# Product

## What is Cyber Defense: Zero Day?

A free lane tower defense in the browser, in the style of Plants vs Zombies: the battlefield is a
motherboard, the resource is falling data packets, the enemies are viruses that get tougher with
every arrival. Its token, $ZDAY, is neither earned nor spent in the game — **holding** it in a
Solana wallet switches on tower skins and a head start.

## Target Users

- **Tower defense players** — a full run in about three minutes, free, nothing to install
- **$ZDAY holders** — the tokens in the wallet show in the game without being spent or staked
- **Web3 game builders** — a small, open example of hold-to-unlock on the iDos Games platform

## Core Value Propositions

1. **A real game first** — five towers with distinct jobs, growing pressure, a global leaderboard;
   the whole loop works with zero tokens
2. **Hold, don't farm** — the game never mints or pays out $ZDAY, so there is nothing to bot
3. **One signature, no transaction** — sign-in is a message signature; playing never costs gas
4. **Perks follow the wallet** — 25, 50 and 100 $ZDAY switch the rewards on, and selling switches
   them off within the hour

## How It Differs

| | Play-to-earn games | NFT-gated games | Cyber Defense |
|---|---|---|---|
| Token is paid out for playing | Yes | No | No |
| Purchase needed before playing | Often | Yes | No |
| What the token does | A reward to sell | An entry pass | Unlocks perks while it is held |
| Reason to run bots | The payout | Little | None — nothing is paid out |
